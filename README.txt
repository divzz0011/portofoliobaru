DIVZZ.exe — Room Explorer (Mobile Ready)

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka index.html di browser modern, atau unggah seluruh folder ke hosting statis.
3. Di HP: tekan MASUK KE RUANGAN, gerakkan karakter memakai D-pad, lalu tekan INTERACT saat tombolnya muncul atau sentuh objek.
4. Di PC: gunakan WASD/tombol panah dan E/Enter.

CATATAN
- Tidak memerlukan instalasi atau backend untuk berjalan sebagai portfolio statis.
- Untuk akses lewat internet, unggah semua file beserta folder assets ke hosting (misalnya GitHub Pages, Netlify, atau Vercel).
- Ilustrasi pada galeri merupakan mockup konsep dan bisa diganti dengan screenshot/foto asli.

CV:
- Dari bagian About Me, tombol LIHAT CV membuka cv.html di tab baru.
- Halaman CV menyediakan tombol Cetak / Simpan PDF dari browser.
- Lengkapi bagian pendidikan dan pengalaman yang masih berupa petunjuk sebelum CV digunakan secara resmi.
- Ganti assets/foto-formal.svg dengan foto formal milik sendiri bila diperlukan.
